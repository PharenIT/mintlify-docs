<script setup lang="ts">
import { Tool, ToolInput, ToolOutput } from '@pharen/ui/components/ai';
</script>

<template>
  <Tool tool-name="Search workspace" state="output-available" class="w-full max-w-lg">

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>
