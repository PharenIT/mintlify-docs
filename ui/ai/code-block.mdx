Use **Code block** to build AI interfaces. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { CodeBlock, CodeBlockContainer, CodeBlockHeader, CodeBlockCopyButton } from '@pharen/ui/components/ai';
```

## Example

```vue
<script setup lang="ts">
import { CodeBlock } from '@pharen/ui/components/ai';
</script>

<template>
  <CodeBlock />
</template>
```
