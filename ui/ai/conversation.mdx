Use **Conversation** to build AI interfaces. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Conversation, ConversationContent, ConversationEmptyState } from '@pharen/ui/components/ai';
```

## Example

```vue
<script setup lang="ts">
import { Conversation, ConversationContent, ConversationEmptyState } from '@pharen/ui/components/ai';
</script>

<template>
  <Conversation>
    <ConversationContent>
      <ConversationEmptyState title="Start a conversation" />
    </ConversationContent>
  </Conversation>
</template>
```

| Export | Purpose |

| `ConversationContent` | Contains the visible content. |
