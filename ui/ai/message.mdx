Use **Message** to build AI interfaces. This page covers every Vue component exported by the public module.

<PharenUiPreview name="message" title="Message preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Message, MessageContent, MessageResponse } from '@pharen/ui/components/ai';
</script>

<template>
  <Message from="assistant">
    <MessageContent>
      <MessageResponse content="Your workflow is ready." />
    </MessageContent>
  </Message>
</template>
```

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>
