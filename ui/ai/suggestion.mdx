Use **Suggestion** to build AI interfaces. This page covers every Vue component exported by the public module.

<PharenUiPreview name="suggestion" title="Suggestion preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Suggestion, Suggestions } from '@pharen/ui/components/ai';

const prompts = ['Summarize this page', 'Create a workflow', 'Explain the errors'];
</script>

<template>
  <Suggestions><Suggestion v-for="prompt in prompts" :key="prompt" :suggestion="prompt" /></Suggestions>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>
