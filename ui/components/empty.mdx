Use **Empty** to present structured product information. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Empty } from '@pharen/ui';
</script>

<template>
  <Empty />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `Empty` | Exported Vue component from this module. |
| `EmptyContent` | Contains the visible content. |
| `EmptyDescription` | Renders supporting description. |
| `EmptyHeader` | Structures the header region. |
| `EmptyMedia` | Exported Vue component from this module. |
| `EmptyTitle` | Renders the accessible title. |
