Use **Empty** to present structured product information. This page covers every Vue component exported by the public module.

<PharenUiPreview name="empty" title="Empty preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Button, Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyTitle } from '@pharen/ui';
</script>

<template>
  <Empty class="w-full max-w-md border">
    <EmptyHeader>
      <EmptyTitle>No workflows yet</EmptyTitle>
      <EmptyDescription>Create a workflow to automate your first process.</EmptyDescription>
    </EmptyHeader>
    <EmptyContent><Button size="sm">Create workflow</Button></EmptyContent>
  </Empty>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Empty` | Exported Vue component from this module. |
| `EmptyContent` | Contains the visible content. |
| `EmptyDescription` | Renders supporting description. |
| `EmptyHeader` | Structures the header region. |
| `EmptyMedia` | Exported Vue component from this module. |
| `EmptyTitle` | Renders the accessible title. |
