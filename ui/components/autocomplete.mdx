Use **Autocomplete** to collect and edit a value. This page covers every Vue component exported by the public module.

<PharenUiPreview name="autocomplete" title="Autocomplete preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Autocomplete, AutocompleteTrigger, AutocompleteContent } from '@pharen/ui';
</script>

<template>
  <Autocomplete>
    <AutocompleteTrigger>Open autocomplete</AutocompleteTrigger>
    <AutocompleteContent>Autocomplete content</AutocompleteContent>
  </Autocomplete>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

```ts
import { Autocomplete, AutocompleteClear, AutocompleteContent, AutocompleteEmpty, AutocompleteGroup, AutocompleteGroupLabel, AutocompleteInput, AutocompleteItem, AutocompleteList, AutocompleteSeparator, AutocompleteTrigger, AutocompleteArrow, AutocompleteBackdrop, AutocompleteCollection, AutocompleteItemIndicator, AutocompletePortal, AutocompletePositioner, AutocompleteRow, AutocompleteStatus, AutocompleteValue } from '@pharen/ui';
```
