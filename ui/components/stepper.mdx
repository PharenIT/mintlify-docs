Use **Stepper** to build an action or navigation pattern. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Stepper, StepperContent, StepperDescription, StepperIndicator, StepperItem, StepperNav, StepperPanel, StepperSeparator, StepperTitle, StepperTrigger } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Stepper, StepperTrigger, StepperContent } from '@pharen/ui';
</script>

<template>
  <Stepper>
    <StepperTrigger>Open stepper</StepperTrigger>
    <StepperContent>Stepper content</StepperContent>
  </Stepper>
</template>
```
