Use **Dropfile** to accept files through a drag-and-drop surface. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { DropFile } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { DropFile } from '@pharen/ui';
</script>

<template>
  <DropFile />
</template>
```
