Use **Input OTP** to collect and edit a value. This page covers every Vue component exported by the public module.

<PharenUiPreview name="input-otp" title="Input OTP preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { InputOTP, InputOTPGroup, InputOTPSlot } from '@pharen/ui';

const code = ref(['4', '2']);
</script>

<template>
  <InputOTP v-model="code" :maxlength="6">
    <InputOTPGroup><InputOTPSlot v-for="index in 6" :key="index" :index="index - 1" /></InputOTPGroup>
  </InputOTP>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { InputOTP, InputOTPGroup, InputOTPSeparator, InputOTPSlot } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |

| `InputOTPGroup` | Groups related items. |
| `InputOTPSeparator` | Separates adjacent regions. |
