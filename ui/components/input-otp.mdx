Use **Input OTP** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { InputOTP, InputOTPGroup, InputOTPSeparator, InputOTPSlot } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { InputOTP } from '@pharen/ui';
</script>

<template>
  <InputOTP />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `InputOTP` | Exported Vue component from this module. |
| `InputOTPGroup` | Groups related items. |
| `InputOTPSeparator` | Separates adjacent regions. |
| `InputOTPSlot` | Exported Vue component from this module. |
