Use **Empty state** to present structured product information. This page covers every Vue component exported by the public module.

<PharenUiPreview name="empty-state" title="Empty state preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { EmptyState } from '@pharen/ui';
</script>

<template>
  <EmptyState
    title="No results found"
    description="Try another search term or clear the filters."
    :icons="['lucide:search', 'lucide:filter', 'lucide:files']"
  />
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { EmptyState } from '@pharen/ui';
```
