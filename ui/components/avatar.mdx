Use **Avatar** to represent a person, team, or agent. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Avatar, AvatarBadge, AvatarFallback, AvatarImage, AvatarUser } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Avatar, AvatarFallback, AvatarImage } from '@pharen/ui';
</script>

<template>
  <Avatar>
    <AvatarImage src="/people/johannes.jpg" alt="Johannes Kanthak" />
    <AvatarFallback>JK</AvatarFallback>
  </Avatar>
</template>
```
