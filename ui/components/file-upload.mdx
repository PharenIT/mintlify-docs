Use **File upload** to select files through an accessible upload control. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { FileUpload } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { FileUpload } from '@pharen/ui';
</script>

<template>
  <FileUpload />
</template>
```
