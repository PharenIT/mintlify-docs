Use **Avatar group** to present structured product information. This page covers every Vue component exported by the public module.

<PharenUiPreview name="avatar-group" title="Avatar group preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { AvatarGroup } from '@pharen/ui';

const people = [
  { fallback: 'JK', alt: 'Johannes Kanthak' },
  { fallback: 'AM', alt: 'Alex Morgan' },
  { fallback: 'SL', alt: 'Sam Lee' },
  { fallback: 'RK', alt: 'Robin Kim' },
  { fallback: 'TN', alt: 'Taylor Nguyen' },
];
</script>

<template>
  <AvatarGroup :items="people" :max="4" size="base" />
</template>
```

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { AvatarGroup, AvatarGroupCount } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `AvatarGroup` | Groups related items. |
