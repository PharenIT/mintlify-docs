Use **Multi select** to choose several values from one option set. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { MultiSelect } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { MultiSelect } from '@pharen/ui';
</script>

<template>
  <MultiSelect />
</template>
```
