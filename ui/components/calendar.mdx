Use **Calendar** to browse and select calendar dates. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Calendar, RangeCalendar } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Calendar } from '@pharen/ui';
</script>

<template>
  <Calendar />
</template>
```
