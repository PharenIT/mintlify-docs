Use **Date picker** to select a date from a popover calendar. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { DatePicker } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { DatePicker } from '@pharen/ui';
</script>

<template>
  <DatePicker />
</template>
```
