Use **Input** to collect a short text value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Input } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Input } from '@pharen/ui';
</script>

<template>
  <Input type="email" placeholder="you@company.com" />
</template>
```
