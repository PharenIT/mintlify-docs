Use **Label** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Label } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Input, Label } from '@pharen/ui';
</script>

<template>
  <div class="grid gap-2">
    <Label for="name">Name</Label>
    <Input id="name" />
  </div>
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `Label` | Labels a value or region. |
