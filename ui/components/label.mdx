Use **Label** to collect and edit a value. This page covers every Vue component exported by the public module.

<PharenUiPreview name="label" title="Label preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Input, Label } from '@pharen/ui';
</script>

<template>
  <div class="grid gap-2">
    <Label for="name">Name</Label>
    <Input id="name" />
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Label } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Label` | Labels a value or region. |
