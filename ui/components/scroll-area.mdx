Use **Scroll area** to organize content and responsive regions. This page covers every Vue component exported by the public module.

<PharenUiPreview name="scroll-area" title="Scroll area preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { ScrollArea } from '@pharen/ui';

const events = ['Workflow created', 'Trigger configured', 'Agent assigned', 'Test run completed', 'Workflow published', 'First run succeeded'];
</script>

<template>
  <ScrollArea class="h-40 w-full max-w-sm rounded-lg border">
    <div class="divide-y p-3">
      <div v-for="event in events" :key="event" class="py-2 text-sm">{{ event }}</div>
    </div>
  </ScrollArea>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

import { ScrollArea, ScrollBar } from '@pharen/ui';
