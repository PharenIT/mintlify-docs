Use **Form** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { FormControl, FormDescription, FormItem, FormLabel, FormMessage, Form, FormField } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { FormControl } from '@pharen/ui';
</script>

<template>
  <FormControl />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `FormControl` | Exported Vue component from this module. |
| `FormDescription` | Renders supporting description. |
| `FormItem` | Represents one item. |
| `FormLabel` | Labels a value or region. |
| `FormMessage` | Exported Vue component from this module. |
| `Form` | Exported Vue component from this module. |
| `FormField` | Exported Vue component from this module. |
