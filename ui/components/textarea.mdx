Use **Textarea** to collect multi-line text. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Textarea } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Textarea } from '@pharen/ui';
</script>

<template>
  <Textarea placeholder="Add a description" />
</template>
```
