Use **Command** to show contextual content or user feedback. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Command, CommandDialog, CommandEmpty, CommandGroup, CommandInput, CommandItem, CommandList, CommandSeparator, CommandShortcut } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Command, CommandItem } from '@pharen/ui';
</script>

<template>
  <Command>
    <CommandItem>First item</CommandItem>
  </Command>
</template>
```
