Use **Stat card** to present structured product information. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { StatCard } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { StatCard } from '@pharen/ui';
</script>

<template>
  <StatCard label="Workflow runs" :value="128" delta="12%" trend="up" />
</template>
```
