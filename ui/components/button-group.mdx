Use **Button group** to build an action or navigation pattern. This page covers every Vue component exported by the public module.

<PharenUiPreview name="button-group" title="Button group preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Button, ButtonGroup, ButtonGroupText } from '@pharen/ui';
</script>

<template>
  <ButtonGroup>
    <Button variant="outline">Back</Button>
    <ButtonGroupText>Step 2 of 3</ButtonGroupText>
    <Button>Continue</Button>
  </ButtonGroup>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `ButtonGroup` | Groups related items. |
| `ButtonGroupSeparator` | Separates adjacent regions. |
| `ButtonGroupText` | Exported Vue component from this module. |
