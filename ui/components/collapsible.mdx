## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Collapsible` | Exported Vue component from this module. |
| `CollapsibleContent` | Contains the visible content. |
| `CollapsibleTrigger` | Opens or activates the component. |
