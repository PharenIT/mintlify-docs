Use **Kbd** to present structured product information. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Kbd, KbdGroup } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Kbd } from '@pharen/ui';
</script>

<template>
  <Kbd />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `Kbd` | Exported Vue component from this module. |
| `KbdGroup` | Groups related items. |
