```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Rating } from '@pharen/ui';

const value = ref(4);
</script>

<template><Rating v-model="value" size="lg" /></template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Rating } from '@pharen/ui';
```
