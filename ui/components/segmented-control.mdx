Use **Segmented control** to collect and edit a value. This page covers every Vue component exported by the public module.

<PharenUiPreview name="segmented-control" title="Segmented control preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { SegmentedControl } from '@pharen/ui';

const period = ref('month');
const options = [
  { label: 'Week', value: 'week' },
  { label: 'Month', value: 'month' },
  { label: 'Year', value: 'year' },
];
</script>

<template><SegmentedControl v-model="period" :options="options" size="md" /></template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

import { SegmentedControl } from '@pharen/ui';
