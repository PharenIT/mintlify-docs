Use **Color picker** to choose and edit a color value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { ColorPicker } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { ColorPicker } from '@pharen/ui';
</script>

<template>
  <ColorPicker />
</template>
```
