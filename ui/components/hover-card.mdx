Use **Hover card** to show contextual content or user feedback. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { HoverCard, HoverCardTrigger, HoverCardContent } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { HoverCard, HoverCardTrigger, HoverCardContent } from '@pharen/ui';
</script>

<template>
  <HoverCard>
    <HoverCardTrigger>Open hover card</HoverCardTrigger>
    <HoverCardContent>Hover card content</HoverCardContent>
  </HoverCard>
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `HoverCard` | Exported Vue component from this module. |
| `HoverCardTrigger` | Opens or activates the component. |
| `HoverCardContent` | Contains the visible content. |
