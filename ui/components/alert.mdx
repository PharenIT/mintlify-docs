Use **Alert** to communicate an important inline message. This page covers every Vue component exported by the public module.

<PharenUiPreview name="alert" title="Alert preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Alert, AlertDescription, AlertTitle } from '@pharen/ui';
</script>

<template>
  <Alert>
    <AlertTitle>Changes saved</AlertTitle>
    <AlertDescription>Your workspace settings are up to date.</AlertDescription>
  </Alert>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Alert, AlertAction, AlertContent, AlertDescription, AlertIcon, AlertTitle, AlertToolbar } from '@pharen/ui';
```

| Export | Purpose |
