Use **Tooltip** to explain an action or value on hover and keyboard focus. This page covers every Vue component exported by the public module.

<PharenUiPreview name="tooltip" title="Tooltip preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Button, Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from '@pharen/ui';
</script>

<template>
  <TooltipProvider>
    <Tooltip>
      <TooltipTrigger as-child><Button variant="outline">Hover or focus</Button></TooltipTrigger>
      <TooltipContent>Open workspace settings</TooltipContent>
    </Tooltip>
  </TooltipProvider>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Tooltip, TooltipProvider, TooltipTrigger, TooltipContent } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Tooltip` | Exported Vue component from this module. |
| `TooltipProvider` | Exported Vue component from this module. |
| `TooltipTrigger` | Opens or activates the component. |
| `TooltipContent` | Contains the visible content. |
