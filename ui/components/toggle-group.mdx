Use **Toggle group** to collect and edit a value. This page covers every Vue component exported by the public module.

<PharenUiPreview name="toggle-group" title="Toggle group preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { ToggleGroup, ToggleGroupItem } from '@pharen/ui';

const alignment = ref('left');
</script>

<template>
  <ToggleGroup v-model="alignment" type="single" variant="outline" :spacing="0">
    <ToggleGroupItem value="left" aria-label="Align left">Left</ToggleGroupItem>
    <ToggleGroupItem value="center" aria-label="Align center">Center</ToggleGroupItem>
    <ToggleGroupItem value="right" aria-label="Align right">Right</ToggleGroupItem>
  </ToggleGroup>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { ToggleGroup, ToggleGroupItem } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `ToggleGroup` | Groups related items. |
| `ToggleGroupItem` | Represents one item. |
