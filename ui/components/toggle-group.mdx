Use **Toggle group** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { ToggleGroup, ToggleGroupItem } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { ToggleGroup, ToggleGroupItem } from '@pharen/ui';
</script>

<template>
  <ToggleGroup>
    <ToggleGroupItem>First item</ToggleGroupItem>
  </ToggleGroup>
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `ToggleGroup` | Groups related items. |
| `ToggleGroupItem` | Represents one item. |
