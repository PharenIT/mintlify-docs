Use **Field** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Field, FieldContent, FieldDescription, FieldError, FieldGroup, FieldLabel, FieldLegend, FieldSeparator, FieldSet, FieldTitle } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Field } from '@pharen/ui';
</script>

<template>
  <Field />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `Field` | Exported Vue component from this module. |
| `FieldContent` | Contains the visible content. |
| `FieldDescription` | Renders supporting description. |
| `FieldError` | Exported Vue component from this module. |
| `FieldGroup` | Groups related items. |
| `FieldLabel` | Labels a value or region. |
| `FieldLegend` | Exported Vue component from this module. |
| `FieldSeparator` | Separates adjacent regions. |
| `FieldSet` | Exported Vue component from this module. |
| `FieldTitle` | Renders the accessible title. |
