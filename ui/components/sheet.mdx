Use **Sheet** to present supporting content beside the current view. This page covers every Vue component exported by the public module.

<PharenUiPreview name="sheet" title="Sheet preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Button, Sheet, SheetContent, SheetDescription, SheetHeader, SheetTitle, SheetTrigger } from '@pharen/ui';
</script>

<template>
  <Sheet>
    <SheetTrigger as-child><Button variant="outline">Open workspace settings</Button></SheetTrigger>
    <SheetContent>
      <SheetHeader>
        <SheetTitle>Workspace settings</SheetTitle>
        <SheetDescription>Manage the name, visibility, and default permissions.</SheetDescription>
      </SheetHeader>
      <div class="mt-6 rounded-lg border bg-muted/30 p-4 text-sm text-muted-foreground">Settings form content</div>
    </SheetContent>
  </Sheet>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Sheet, SheetClose, SheetContent, SheetDescription, SheetFooter, SheetHeader, SheetTitle, SheetTrigger } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Sheet` | Exported Vue component from this module. |
| `SheetClose` | Exported Vue component from this module. |
| `SheetContent` | Contains the visible content. |
| `SheetDescription` | Renders supporting description. |
| `SheetFooter` | Structures the footer region. |
| `SheetHeader` | Structures the header region. |
| `SheetTitle` | Renders the accessible title. |
| `SheetTrigger` | Opens or activates the component. |
