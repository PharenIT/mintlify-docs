Use **Frame** to present structured product information. This page covers every Vue component exported by the public module.

<PharenUiPreview name="frame" title="Frame preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Frame, FrameDescription, FrameFooter, FrameHeader, FramePanel, FrameTitle } from '@pharen/ui';
</script>

<template>
  <Frame class="w-full max-w-md">
    <FrameHeader>
      <FrameTitle>Agent activity</FrameTitle>
      <FrameDescription>Latest run for the research agent.</FrameDescription>
    </FrameHeader>
    <FramePanel>
      <div class="flex items-center justify-between text-sm">
        <span>Processed documents</span><strong>24</strong>
      </div>
    </FramePanel>
    <FrameFooter><span class="text-xs text-muted-foreground">Updated just now</span></FrameFooter>
  </Frame>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Frame, FrameDescription, FrameFooter, FrameHeader, FramePanel, FrameTitle } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Frame` | Exported Vue component from this module. |
| `FrameDescription` | Renders supporting description. |
| `FrameFooter` | Structures the footer region. |
| `FrameHeader` | Structures the header region. |
| `FramePanel` | Exported Vue component from this module. |
| `FrameTitle` | Renders the accessible title. |
