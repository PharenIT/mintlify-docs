Use **Frame** to present structured product information. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Frame, FrameDescription, FrameFooter, FrameHeader, FramePanel, FrameTitle } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Frame } from '@pharen/ui';
</script>

<template>
  <Frame />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `Frame` | Exported Vue component from this module. |
| `FrameDescription` | Renders supporting description. |
| `FrameFooter` | Structures the footer region. |
| `FrameHeader` | Structures the header region. |
| `FramePanel` | Exported Vue component from this module. |
| `FrameTitle` | Renders the accessible title. |
