Use **Native select** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { NativeSelect, NativeSelectOptGroup, NativeSelectOption } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { NativeSelect } from '@pharen/ui';
</script>

<template>
  <NativeSelect />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `NativeSelect` | Exported Vue component from this module. |
| `NativeSelectOptGroup` | Groups related items. |
| `NativeSelectOption` | Exported Vue component from this module. |
