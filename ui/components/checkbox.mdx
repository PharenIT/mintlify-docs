Use **Checkbox** to collect and edit a value. This page covers every Vue component exported by the public module.

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Checkbox, Label } from '@pharen/ui';
</script>

<template>
  <div class="flex items-center gap-2">
    <Checkbox id="updates" />
    <Label for="updates">Email me product updates</Label>
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Checkbox } from '@pharen/ui';
```
