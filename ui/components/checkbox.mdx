Use **Checkbox** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Checkbox } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Checkbox, Label } from '@pharen/ui';
</script>

<template>
  <div class="flex items-center gap-2">
    <Checkbox id="updates" />
    <Label for="updates">Email me product updates</Label>
  </div>
</template>
```
