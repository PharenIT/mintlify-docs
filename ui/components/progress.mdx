Use **Progress** to communicate completion against a known total. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Progress } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Progress } from '@pharen/ui';
</script>

<template>
  <Progress :model-value="64" />
</template>
```
