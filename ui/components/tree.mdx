Use **Tree** to build an action or navigation pattern. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Tree, TreeDragLine, TreeItem, TreeItemLabel } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Tree, TreeItem } from '@pharen/ui';
</script>

<template>
  <Tree>
    <TreeItem>First item</TreeItem>
  </Tree>
</template>
```
