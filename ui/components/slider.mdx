Use **Slider** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Slider } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Slider } from '@pharen/ui';
</script>

<template>
  <Slider :default-value="[40]" :max="100" :step="1" />
</template>
```
