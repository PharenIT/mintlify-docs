Use **Dialog** to focus a task in a modal surface. This page covers every Vue component exported by the public module.

<PharenUiPreview name="dialog" title="Dialog preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Button, Dialog, DialogContent, DialogDescription, DialogHeader, DialogTitle, DialogTrigger } from '@pharen/ui';
</script>

<template>
  <Dialog>
    <DialogTrigger as-child><Button variant="outline">Open dialog</Button></DialogTrigger>
    <DialogContent>
      <DialogHeader>
        <DialogTitle>Edit workspace</DialogTitle>
        <DialogDescription>Update the workspace name and details.</DialogDescription>
      </DialogHeader>
    </DialogContent>
  </Dialog>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Dialog, DialogClose, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogOverlay, DialogPortal, DialogScrollContent, DialogTitle, DialogTrigger } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Dialog` | Exported Vue component from this module. |
| `DialogClose` | Exported Vue component from this module. |
| `DialogContent` | Contains the visible content. |
| `DialogDescription` | Renders supporting description. |
| `DialogFooter` | Structures the footer region. |
| `DialogHeader` | Structures the header region. |
| `DialogOverlay` | Exported Vue component from this module. |
| `DialogPortal` | Exported Vue component from this module. |
| `DialogScrollContent` | Contains the visible content. |
| `DialogTitle` | Renders the accessible title. |
| `DialogTrigger` | Opens or activates the component. |
