Use **Item** to present structured product information. This page covers every Vue component exported by the public module.

<PharenUiPreview name="item" title="Item preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { Badge, Button, Item, ItemActions, ItemContent, ItemDescription, ItemTitle } from '@pharen/ui';
</script>

<template>
  <Item variant="outline" class="w-full max-w-md">
    <ItemContent>
      <ItemTitle>Customer onboarding</ItemTitle>
      <ItemDescription>Runs when a new account is created.</ItemDescription>
    </ItemContent>
    <ItemActions><Badge variant="success">Active</Badge><Button size="sm" variant="ghost">Open</Button></ItemActions>
  </Item>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>

## Usage

```ts
import { Item, ItemActions, ItemContent, ItemDescription, ItemFooter, ItemGroup, ItemHeader, ItemMedia, ItemSeparator, ItemTitle } from '@pharen/ui';
```

## Exports

| Export | Purpose |
| --- | --- |
| `Item` | Represents one item. |
| `ItemActions` | Exported Vue component from this module. |
| `ItemContent` | Contains the visible content. |
| `ItemDescription` | Renders supporting description. |
| `ItemFooter` | Structures the footer region. |
| `ItemGroup` | Groups related items. |
| `ItemHeader` | Structures the header region. |
| `ItemMedia` | Exported Vue component from this module. |
| `ItemSeparator` | Separates adjacent regions. |
| `ItemTitle` | Renders the accessible title. |
