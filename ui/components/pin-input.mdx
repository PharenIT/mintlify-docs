Use **Pin input** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { PinInput, PinInputGroup, PinInputSeparator, PinInputSlot } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { PinInput } from '@pharen/ui';
</script>

<template>
  <PinInput />
</template>
```

## Exports

| Export | Purpose |
| --- | --- |
| `PinInput` | Exported Vue component from this module. |
| `PinInputGroup` | Groups related items. |
| `PinInputSeparator` | Separates adjacent regions. |
| `PinInputSlot` | Exported Vue component from this module. |
