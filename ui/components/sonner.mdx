Use **Sonner** to show transient toast notifications. This page covers every Vue component exported by the public module.

<PharenUiPreview name="sonner" title="Sonner preview" />

<Accordion title="View code">

```vue
<script setup lang="ts">
import { onMounted } from 'vue';
import { Button, Sonner, toast } from '@pharen/ui';

const showToast = () => toast.success('Workflow published', { description: 'The automation is now active.', duration: Infinity });
onMounted(showToast);
</script>

<template>
  <div><Button variant="outline" @click="showToast">Show notification</Button><Sonner position="top-center" /></div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Import `@pharen/ui/styles.css` exactly once in your application entrypoint.
</Note>
