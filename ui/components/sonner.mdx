Use **Sonner** to show transient toast notifications. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Sonner, Toaster } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Sonner } from '@pharen/ui';
</script>

<template>
  <Sonner />
</template>
```
