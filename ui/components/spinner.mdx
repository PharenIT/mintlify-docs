Use **Spinner** to communicate indeterminate progress. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Spinner } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Spinner } from '@pharen/ui';
</script>

<template>
  <Spinner />
</template>
```
