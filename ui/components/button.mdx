Use **Button** to trigger a user action. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Button } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Button } from '@pharen/ui';
</script>

<template>
  <Button>Save changes</Button>
</template>
```
