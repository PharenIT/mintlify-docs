Use **Pagination** to navigate through paginated results. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Pagination, PaginationContent, PaginationEllipsis, PaginationFirst, PaginationItem, PaginationLast, PaginationLink, PaginationNext, PaginationPrevious } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Pagination, PaginationItem } from '@pharen/ui';
</script>

<template>
  <Pagination>
    <PaginationItem>First item</PaginationItem>
  </Pagination>
</template>
```
