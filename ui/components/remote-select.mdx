Use **Remote select** to search and choose options loaded from a remote source. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { RemoteSelect } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { RemoteSelect } from '@pharen/ui';
</script>

<template>
  <RemoteSelect />
</template>
```
