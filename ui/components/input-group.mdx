Use **Input group** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupInput, InputGroupText, InputGroupTextarea } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { InputGroup } from '@pharen/ui';
</script>

<template>
  <InputGroup />
</template>
```
