Use **Resizable** to organize content and responsive regions. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { ResizableHandle } from '@pharen/ui';
</script>

<template>
  <ResizableHandle />
</template>
```
