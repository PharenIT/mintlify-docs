Use **Date selector** to compose structured date selection controls. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { DateSelector } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { DateSelector } from '@pharen/ui';
</script>

<template>
  <DateSelector />
</template>
```
