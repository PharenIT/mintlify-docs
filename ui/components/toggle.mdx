Use **Toggle** to collect and edit a value. This page covers every Vue component exported by the public module.

<Note>
  Install the package and import its styles once. See [Installation](/ui/installation) for the complete setup.
</Note>

## Import

```ts
import { Toggle } from '@pharen/ui';
```

## Example

```vue
<script setup lang="ts">
import { Toggle } from '@pharen/ui';
</script>

<template>
  <Toggle aria-label="Toggle bold">Bold</Toggle>
</template>
```
