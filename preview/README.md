# Pharen UI live previews

This small Vite library bundles the real Vue examples used by the Mintlify component pages. Mintlify loads the generated JavaScript and CSS inside an isolated iframe.

Run `npm install` and `npm run build` in this directory after updating `@pharen/ui`, then copy `dist/pharen-ui-preview.js` and `dist/pharen-ui-preview.css` to `/ui-preview/`.
