Pharen UI ist die gemeinsame Komponentenbibliothek für Pharen-Produkte. Sie stellt zugängliche Vue-3-Bausteine, Tailwind-CSS-Tokens und komplexe Produktmuster über `@pharen/ui` bereit.

<Info>
  Diese Dokumentation entspricht Paketversion `0.0.18`.
</Info>

## Schnellstart

<Steps>
  <Step title="Paket installieren">
    `npm install @pharen/ui`
  </Step>
  <Step title="Styles laden">
    Importiere `@pharen/ui/styles.css` einmal in deinem App-Einstiegspunkt.
  </Step>
  <Step title="Komponente verwenden">
    `import { Button } from '@pharen/ui'`
  </Step>
</Steps>
