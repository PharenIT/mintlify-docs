Mit **Message** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Message, MessageContent, MessageActions, MessageResponse, MessageToolbar, MessageBranch, MessageBranchContent, MessageBranchSelector, MessageBranchPrevious, MessageBranchNext, MessageBranchPage } from '@pharen/ui/components/ai';
```

## Beispiel

```vue
<script setup lang="ts">
import { Message, MessageContent, MessageResponse } from '@pharen/ui/components/ai';
</script>

<template>
  <Message from="assistant">
    <MessageContent>
      <MessageResponse content="Your workflow is ready." />
    </MessageContent>
  </Message>
</template>
```
