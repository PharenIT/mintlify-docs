Mit **Thinking label** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { ThinkingLabel } from '@pharen/ui/components/ai';
```

## Beispiel

```vue
<script setup lang="ts">
import { ThinkingLabel } from '@pharen/ui/components/ai';
</script>

<template>
  <ThinkingLabel />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `ThinkingLabel` | Beschriftet einen Wert oder Bereich. |
