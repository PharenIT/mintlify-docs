Mit **Thinking label** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="thinking-label" title="Thinking label Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ThinkingLabel } from '@pharen/ui/components/ai';
</script>

<template><ThinkingLabel label="Thinking about the next step" active :size="20" /></template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { ThinkingLabel } from '@pharen/ui/components/ai';
```
