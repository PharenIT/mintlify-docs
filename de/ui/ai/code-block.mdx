Mit **Code block** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { CodeBlock, CodeBlockContainer, CodeBlockHeader, CodeBlockCopyButton } from '@pharen/ui/components/ai';
```

## Beispiel

```vue
<script setup lang="ts">
import { CodeBlock } from '@pharen/ui/components/ai';
</script>

<template>
  <CodeBlock />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `CodeBlock` | Exportierte Vue-Komponente dieses Moduls. |
| `CodeBlockContainer` | Exportierte Vue-Komponente dieses Moduls. |
| `CodeBlockHeader` | Strukturiert den Kopfbereich. |
| `CodeBlockCopyButton` | Exportierte Vue-Komponente dieses Moduls. |
