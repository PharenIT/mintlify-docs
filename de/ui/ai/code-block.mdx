Mit **Code block** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="code-block" title="Code block Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { CodeBlock } from '@pharen/ui/components/ai';

const code = `import { Button } from '@pharen/ui';\n\n<Button>Save changes</Button>`;
</script>

<template><CodeBlock :code="code" language="vue" show-line-numbers /></template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { CodeBlock, CodeBlockContainer, CodeBlockHeader, CodeBlockCopyButton } from '@pharen/ui/components/ai';
```
