Mit **Suggestion** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="suggestion" title="Suggestion Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Suggestion, Suggestions } from '@pharen/ui/components/ai';

const prompts = ['Summarize this page', 'Create a workflow', 'Explain the errors'];
</script>

<template>
  <Suggestions><Suggestion v-for="prompt in prompts" :key="prompt" :suggestion="prompt" /></Suggestions>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Suggestions, Suggestion } from '@pharen/ui/components/ai';
```
