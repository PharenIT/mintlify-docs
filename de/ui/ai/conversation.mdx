Mit **Conversation** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="conversation" title="Conversation Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Conversation, ConversationContent, ConversationEmptyState } from '@pharen/ui/components/ai';
</script>

<template>
  <Conversation>
    <ConversationContent>
      <ConversationEmptyState title="Start a conversation" />
    </ConversationContent>
  </Conversation>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Conversation, ConversationContent, ConversationEmptyState } from '@pharen/ui/components/ai';
```

## Exporte

| Export | Aufgabe |

| `ConversationContent` | Enthält den sichtbaren Inhalt. |
| `ConversationEmptyState` | Exportierte Vue-Komponente dieses Moduls. |
