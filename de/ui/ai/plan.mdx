Mit **Plan** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Plan, PlanTask } from '@pharen/ui/components/ai';
```

## Beispiel

```vue
<script setup lang="ts">
import { Plan } from '@pharen/ui/components/ai';
</script>

<template>
  <Plan />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
