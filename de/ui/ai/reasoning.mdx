Mit **Reasoning** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="reasoning" title="Reasoning Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Reasoning } from '@pharen/ui/components/ai';
</script>

<template>
  <Reasoning :duration="4" class="w-full max-w-lg">
    I compared the workflow history with the current configuration and found two changes.
  </Reasoning>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Reasoning } from '@pharen/ui/components/ai';
```
