Mit **Tool** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Tool, ToolInput, ToolOutput } from '@pharen/ui/components/ai';
```

## Beispiel

```vue
<script setup lang="ts">
import { Tool, ToolInput, ToolOutput } from '@pharen/ui/components/ai';
</script>

<template>
  <Tool title="Search workspace" state="output-available">
    <ToolInput :input="{ query: 'Q3 plan' }" />
    <ToolOutput output="3 matching documents" />
  </Tool>
</template>
```
