Mit **Tool** kannst du AI-Oberflächen aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="tool" title="Tool Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Tool, ToolInput, ToolOutput } from '@pharen/ui/components/ai';
</script>

<template>
  <Tool tool-name="Search workspace" state="output-available" class="w-full max-w-lg">
    <ToolInput :input="{ query: 'Q3 plan' }" />
    <ToolOutput output="3 matching documents" />
  </Tool>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Tool, ToolInput, ToolOutput } from '@pharen/ui/components/ai';
```
