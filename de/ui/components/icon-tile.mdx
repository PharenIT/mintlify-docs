Mit **Icon tile** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { IconTile } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { IconTile } from '@pharen/ui';
</script>

<template>
  <IconTile />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `IconTile` | Exportierte Vue-Komponente dieses Moduls. |
