Mit **Icon tile** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="icon-tile" title="Icon tile Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Icon } from '@iconify/vue';
import { IconTile } from '@pharen/ui';
</script>

<template>
  <div class="flex items-center gap-3">
    <IconTile variant="primary" size="lg"><Icon icon="lucide:sparkles" /></IconTile>
    <div><p class="text-sm font-medium">AI automation</p><p class="text-xs text-muted-foreground">Ready to run</p></div>
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { IconTile } from '@pharen/ui';
```
