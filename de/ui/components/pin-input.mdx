Mit **Pin input** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="pin-input" title="Pin input Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { PinInput, PinInputGroup, PinInputSeparator, PinInputSlot } from '@pharen/ui';

const pin = ref(['1', '5', '8']);
</script>

<template>
  <PinInput v-model="pin" :maxlength="6">
    <PinInputGroup><PinInputSlot v-for="index in 3" :key="index" :index="index - 1" /></PinInputGroup>
    <PinInputSeparator />
    <PinInputGroup><PinInputSlot v-for="index in [3, 4, 5]" :key="index" :index="index" /></PinInputGroup>
  </PinInput>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { PinInput, PinInputGroup, PinInputSeparator, PinInputSlot } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `PinInput` | Exportierte Vue-Komponente dieses Moduls. |
| `PinInputGroup` | Gruppiert zusammengehörige Elemente. |
| `PinInputSeparator` | Trennt benachbarte Bereiche. |
| `PinInputSlot` | Exportierte Vue-Komponente dieses Moduls. |
