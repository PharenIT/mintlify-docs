Mit **Button group** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="button-group" title="Button group Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Button, ButtonGroup, ButtonGroupText } from '@pharen/ui';
</script>

<template>
  <ButtonGroup>
    <Button variant="outline">Back</Button>
    <ButtonGroupText>Step 2 of 3</ButtonGroupText>
    <Button>Continue</Button>
  </ButtonGroup>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `ButtonGroup` | Gruppiert zusammengehörige Elemente. |
| `ButtonGroupSeparator` | Trennt benachbarte Bereiche. |
| `ButtonGroupText` | Exportierte Vue-Komponente dieses Moduls. |
