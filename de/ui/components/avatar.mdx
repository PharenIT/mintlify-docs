Mit **Avatar** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="avatar" title="Avatar Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Avatar, AvatarFallback, AvatarImage } from '@pharen/ui';
</script>

<template>
  <Avatar>
    <AvatarImage src="/people/johannes.jpg" alt="Johannes Kanthak" />
    <AvatarFallback>JK</AvatarFallback>
  </Avatar>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Avatar, AvatarBadge, AvatarFallback, AvatarImage, AvatarUser } from '@pharen/ui';
```
