Mit **Avatar** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Avatar, AvatarBadge, AvatarFallback, AvatarImage, AvatarUser } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Avatar, AvatarFallback, AvatarImage } from '@pharen/ui';
</script>

<template>
  <Avatar>
    <AvatarImage src="/people/johannes.jpg" alt="Johannes Kanthak" />
    <AvatarFallback>JK</AvatarFallback>
  </Avatar>
</template>
```
