Mit **Spinner** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Spinner } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Spinner } from '@pharen/ui';
</script>

<template>
  <Spinner />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Spinner` | Exportierte Vue-Komponente dieses Moduls. |
