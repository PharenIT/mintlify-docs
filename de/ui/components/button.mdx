Mit **Button** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Button } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Button } from '@pharen/ui';
</script>

<template>
  <Button>Save changes</Button>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Button` | Exportierte Vue-Komponente dieses Moduls. |
