Mit **Plan** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="plan" title="Plan Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Badge, Plan, PlanAction, PlanContent, PlanDescription, PlanFooter, PlanHeader, PlanTitle, PlanTrigger } from '@pharen/ui';
</script>

<template>
  <Plan default-open class="w-full max-w-lg">
    <PlanHeader>
      <div><PlanTitle>Launch workflow</PlanTitle><PlanDescription>Review the execution plan before starting.</PlanDescription></div>
      <PlanAction><Badge variant="secondary">3 steps</Badge><PlanTrigger /></PlanAction>
    </PlanHeader>
    <PlanContent>
      <ol class="grid gap-2 text-sm"><li>1. Load workspace records</li><li>2. Generate the weekly summary</li><li>3. Send the result to Slack</li></ol>
    </PlanContent>
    <PlanFooter>Estimated duration: 45 seconds</PlanFooter>
  </Plan>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Plan, PlanHeader, PlanTitle, PlanDescription, PlanAction, PlanContent, PlanFooter, PlanTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Plan` | Exportierte Vue-Komponente dieses Moduls. |
| `PlanHeader` | Strukturiert den Kopfbereich. |
| `PlanTitle` | Zeigt den zugänglichen Titel. |
| `PlanDescription` | Zeigt ergänzende Beschreibung. |
| `PlanAction` | Exportierte Vue-Komponente dieses Moduls. |
| `PlanContent` | Enthält den sichtbaren Inhalt. |
| `PlanFooter` | Strukturiert den Fußbereich. |
| `PlanTrigger` | Öffnet oder aktiviert die Komponente. |
