Mit **Live waveform** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="live-waveform" title="Live waveform Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { LiveWaveform } from '@pharen/ui';
</script>

<template>
  <div class="w-full max-w-md rounded-lg border p-4">
    <div class="mb-3 flex items-center justify-between text-sm"><span class="font-medium">Microphone input</span><span class="text-muted-foreground">Waiting</span></div>
    <LiveWaveform label="Microphone input" class="text-primary" />
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { LiveWaveform } from '@pharen/ui';
```
