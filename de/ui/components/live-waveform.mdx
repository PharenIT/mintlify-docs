Mit **Live waveform** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { LiveWaveform } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { LiveWaveform } from '@pharen/ui';
</script>

<template>
  <LiveWaveform />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `LiveWaveform` | Exportierte Vue-Komponente dieses Moduls. |
