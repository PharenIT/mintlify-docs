Mit **Empty** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="empty" title="Empty Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Button, Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyTitle } from '@pharen/ui';
</script>

<template>
  <Empty class="w-full max-w-md border">
    <EmptyHeader>
      <EmptyTitle>No workflows yet</EmptyTitle>
      <EmptyDescription>Create a workflow to automate your first process.</EmptyDescription>
    </EmptyHeader>
    <EmptyContent><Button size="sm">Create workflow</Button></EmptyContent>
  </Empty>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Empty` | Exportierte Vue-Komponente dieses Moduls. |
| `EmptyContent` | Enthält den sichtbaren Inhalt. |
| `EmptyDescription` | Zeigt ergänzende Beschreibung. |
| `EmptyHeader` | Strukturiert den Kopfbereich. |
| `EmptyMedia` | Exportierte Vue-Komponente dieses Moduls. |
| `EmptyTitle` | Zeigt den zugänglichen Titel. |
