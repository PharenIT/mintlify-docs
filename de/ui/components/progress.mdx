Mit **Progress** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Progress } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Progress } from '@pharen/ui';
</script>

<template>
  <Progress :model-value="64" />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Progress` | Exportierte Vue-Komponente dieses Moduls. |
