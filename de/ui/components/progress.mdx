Mit **Progress** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="progress" title="Progress Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Progress } from '@pharen/ui';
</script>

<template>
  <div class="w-full max-w-sm space-y-2">
    <div class="flex justify-between text-sm"><span>Workspace setup</span><span class="font-medium">64%</span></div>
    <Progress :model-value="64" />
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Progress } from '@pharen/ui';
```
