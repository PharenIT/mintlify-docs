Mit **Dialog** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="dialog" title="Dialog Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Button, Dialog, DialogContent, DialogDescription, DialogHeader, DialogTitle, DialogTrigger } from '@pharen/ui';
</script>

<template>
  <Dialog>
    <DialogTrigger as-child><Button variant="outline">Open dialog</Button></DialogTrigger>
    <DialogContent>
      <DialogHeader>
        <DialogTitle>Edit workspace</DialogTitle>
        <DialogDescription>Update the workspace name and details.</DialogDescription>
      </DialogHeader>
    </DialogContent>
  </Dialog>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Dialog, DialogClose, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogOverlay, DialogPortal, DialogScrollContent, DialogTitle, DialogTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Dialog` | Exportierte Vue-Komponente dieses Moduls. |
| `DialogClose` | Exportierte Vue-Komponente dieses Moduls. |
| `DialogContent` | Enthält den sichtbaren Inhalt. |
| `DialogDescription` | Zeigt ergänzende Beschreibung. |
| `DialogFooter` | Strukturiert den Fußbereich. |
| `DialogHeader` | Strukturiert den Kopfbereich. |
| `DialogOverlay` | Exportierte Vue-Komponente dieses Moduls. |
| `DialogPortal` | Exportierte Vue-Komponente dieses Moduls. |
| `DialogScrollContent` | Enthält den sichtbaren Inhalt. |
| `DialogTitle` | Zeigt den zugänglichen Titel. |
| `DialogTrigger` | Öffnet oder aktiviert die Komponente. |
