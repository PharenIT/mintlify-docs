Mit **Navigation menu** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="navigation-menu" title="Navigation menu Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { NavigationMenu, NavigationMenuContent, NavigationMenuItem, NavigationMenuLink, NavigationMenuList, NavigationMenuTrigger } from '@pharen/ui';
</script>

<template>
  <NavigationMenu>
    <NavigationMenuList>
      <NavigationMenuItem>
        <NavigationMenuTrigger>Products</NavigationMenuTrigger>
        <NavigationMenuContent class="p-3">
          <div class="grid w-72 gap-2">
            <NavigationMenuLink href="#hub" class="rounded-md p-2 hover:bg-accent"><strong class="block text-sm">Pharen Hub</strong><span class="text-xs text-muted-foreground">Workflows and agents in one place.</span></NavigationMenuLink>
            <NavigationMenuLink href="#ui" class="rounded-md p-2 hover:bg-accent"><strong class="block text-sm">Pharen UI</strong><span class="text-xs text-muted-foreground">Reusable Vue components.</span></NavigationMenuLink>
          </div>
        </NavigationMenuContent>
      </NavigationMenuItem>
      <NavigationMenuItem><NavigationMenuLink href="#docs" class="px-4 py-2 text-sm">Docs</NavigationMenuLink></NavigationMenuItem>
    </NavigationMenuList>
  </NavigationMenu>
</template>
```

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { NavigationMenu, NavigationMenuContent, NavigationMenuIndicator, NavigationMenuItem, NavigationMenuLink, NavigationMenuList, NavigationMenuTrigger, NavigationMenuViewport } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `NavigationMenu` | Exportierte Vue-Komponente dieses Moduls. |
| `NavigationMenuContent` | Enthält den sichtbaren Inhalt. |
| `NavigationMenuIndicator` | Exportierte Vue-Komponente dieses Moduls. |
| `NavigationMenuItem` | Stellt ein einzelnes Element dar. |
| `NavigationMenuLink` | Exportierte Vue-Komponente dieses Moduls. |
| `NavigationMenuList` | Exportierte Vue-Komponente dieses Moduls. |
| `NavigationMenuTrigger` | Öffnet oder aktiviert die Komponente. |
| `NavigationMenuViewport` | Exportierte Vue-Komponente dieses Moduls. |
