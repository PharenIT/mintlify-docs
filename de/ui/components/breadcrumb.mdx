Mit **Breadcrumb** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="breadcrumb" title="Breadcrumb Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Breadcrumb, BreadcrumbItem, BreadcrumbLink, BreadcrumbList, BreadcrumbPage, BreadcrumbSeparator } from '@pharen/ui';
</script>

<template>
  <Breadcrumb>
    <BreadcrumbList>
      <BreadcrumbItem><BreadcrumbLink href="/">Home</BreadcrumbLink></BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem><BreadcrumbPage>Settings</BreadcrumbPage></BreadcrumbItem>
    </BreadcrumbList>
  </Breadcrumb>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Breadcrumb, BreadcrumbEllipsis, BreadcrumbItem, BreadcrumbLink, BreadcrumbList, BreadcrumbPage, BreadcrumbSeparator } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Breadcrumb` | Exportierte Vue-Komponente dieses Moduls. |
| `BreadcrumbEllipsis` | Exportierte Vue-Komponente dieses Moduls. |
| `BreadcrumbItem` | Stellt ein einzelnes Element dar. |
| `BreadcrumbLink` | Exportierte Vue-Komponente dieses Moduls. |
| `BreadcrumbList` | Exportierte Vue-Komponente dieses Moduls. |
| `BreadcrumbPage` | Exportierte Vue-Komponente dieses Moduls. |
| `BreadcrumbSeparator` | Trennt benachbarte Bereiche. |
