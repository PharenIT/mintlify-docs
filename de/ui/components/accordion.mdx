Mit **Accordion** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="accordion" title="Accordion Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@pharen/ui';
</script>

<template>
  <Accordion type="single" collapsible>
    <AccordionItem value="billing">
      <AccordionTrigger>How does billing work?</AccordionTrigger>
      <AccordionContent>Plans are billed per workspace.</AccordionContent>
    </AccordionItem>
  </Accordion>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Accordion` | Exportierte Vue-Komponente dieses Moduls. |
| `AccordionContent` | Enthält den sichtbaren Inhalt. |
| `AccordionItem` | Stellt ein einzelnes Element dar. |
| `AccordionTrigger` | Öffnet oder aktiviert die Komponente. |
