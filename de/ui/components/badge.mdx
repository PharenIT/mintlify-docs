Mit **Badge** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Badge, BadgeButton, BadgeDot } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Badge } from '@pharen/ui';
</script>

<template>
  <Badge variant="secondary">Active</Badge>
</template>
```
