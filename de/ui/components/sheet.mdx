Mit **Sheet** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="sheet" title="Sheet Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Sheet, SheetTrigger, SheetContent } from '@pharen/ui';
</script>

<template>
  <Sheet>
    <SheetTrigger>Open sheet</SheetTrigger>
    <SheetContent>Sheet content</SheetContent>
  </Sheet>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Sheet, SheetClose, SheetContent, SheetDescription, SheetFooter, SheetHeader, SheetTitle, SheetTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Sheet` | Exportierte Vue-Komponente dieses Moduls. |
| `SheetClose` | Exportierte Vue-Komponente dieses Moduls. |
| `SheetContent` | Enthält den sichtbaren Inhalt. |
| `SheetDescription` | Zeigt ergänzende Beschreibung. |
| `SheetFooter` | Strukturiert den Fußbereich. |
| `SheetHeader` | Strukturiert den Kopfbereich. |
| `SheetTitle` | Zeigt den zugänglichen Titel. |
| `SheetTrigger` | Öffnet oder aktiviert die Komponente. |
