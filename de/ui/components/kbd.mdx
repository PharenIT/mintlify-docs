Mit **Kbd** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="kbd" title="Kbd Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Kbd } from '@pharen/ui';
</script>

<template>
  <div class="flex items-center gap-2 text-sm text-muted-foreground">
    Open search <span class="flex gap-1"><Kbd>⌘</Kbd><Kbd>K</Kbd></span>
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Kbd, KbdGroup } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Kbd` | Exportierte Vue-Komponente dieses Moduls. |
| `KbdGroup` | Gruppiert zusammengehörige Elemente. |
