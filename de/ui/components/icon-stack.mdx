Mit **Icon stack** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { IconStack } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { IconStack } from '@pharen/ui';
</script>

<template>
  <IconStack />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `IconStack` | Exportierte Vue-Komponente dieses Moduls. |
