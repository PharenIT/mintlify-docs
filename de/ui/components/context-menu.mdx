Mit **Context menu** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="context-menu" title="Context menu Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ContextMenu, ContextMenuTrigger, ContextMenuContent } from '@pharen/ui';
</script>

<template>
  <ContextMenu>
    <ContextMenuTrigger>Open context menu</ContextMenuTrigger>
    <ContextMenuContent>Context menu content</ContextMenuContent>
  </ContextMenu>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { ContextMenu, ContextMenuCheckboxItem, ContextMenuContent, ContextMenuGroup, ContextMenuItem, ContextMenuLabel, ContextMenuPortal, ContextMenuRadioGroup, ContextMenuRadioItem, ContextMenuSeparator, ContextMenuShortcut, ContextMenuSub, ContextMenuSubContent, ContextMenuSubTrigger, ContextMenuTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `ContextMenu` | Exportierte Vue-Komponente dieses Moduls. |
| `ContextMenuCheckboxItem` | Stellt ein einzelnes Element dar. |
| `ContextMenuContent` | Enthält den sichtbaren Inhalt. |
| `ContextMenuGroup` | Gruppiert zusammengehörige Elemente. |
| `ContextMenuItem` | Stellt ein einzelnes Element dar. |
| `ContextMenuLabel` | Beschriftet einen Wert oder Bereich. |
| `ContextMenuPortal` | Exportierte Vue-Komponente dieses Moduls. |
| `ContextMenuRadioGroup` | Gruppiert zusammengehörige Elemente. |
| `ContextMenuRadioItem` | Stellt ein einzelnes Element dar. |
| `ContextMenuSeparator` | Trennt benachbarte Bereiche. |
| `ContextMenuShortcut` | Exportierte Vue-Komponente dieses Moduls. |
| `ContextMenuSub` | Exportierte Vue-Komponente dieses Moduls. |
| `ContextMenuSubContent` | Enthält den sichtbaren Inhalt. |
| `ContextMenuSubTrigger` | Öffnet oder aktiviert die Komponente. |
| `ContextMenuTrigger` | Öffnet oder aktiviert die Komponente. |
