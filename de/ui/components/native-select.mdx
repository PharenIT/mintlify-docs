Mit **Native select** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="native-select" title="Native select Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { NativeSelect, NativeSelectOption } from '@pharen/ui';

const role = ref('member');
</script>

<template>
  <NativeSelect v-model="role" aria-label="Role">
    <NativeSelectOption value="admin">Admin</NativeSelectOption>
    <NativeSelectOption value="member">Member</NativeSelectOption>
    <NativeSelectOption value="viewer">Viewer</NativeSelectOption>
  </NativeSelect>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { NativeSelect, NativeSelectOptGroup, NativeSelectOption } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `NativeSelect` | Exportierte Vue-Komponente dieses Moduls. |
| `NativeSelectOptGroup` | Gruppiert zusammengehörige Elemente. |
| `NativeSelectOption` | Exportierte Vue-Komponente dieses Moduls. |
