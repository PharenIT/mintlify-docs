Mit **Item** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="item" title="Item Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Badge, Button, Item, ItemActions, ItemContent, ItemDescription, ItemTitle } from '@pharen/ui';
</script>

<template>
  <Item variant="outline" class="w-full max-w-md">
    <ItemContent>
      <ItemTitle>Customer onboarding</ItemTitle>
      <ItemDescription>Runs when a new account is created.</ItemDescription>
    </ItemContent>
    <ItemActions><Badge variant="success">Active</Badge><Button size="sm" variant="ghost">Open</Button></ItemActions>
  </Item>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Item, ItemActions, ItemContent, ItemDescription, ItemFooter, ItemGroup, ItemHeader, ItemMedia, ItemSeparator, ItemTitle } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Item` | Stellt ein einzelnes Element dar. |
| `ItemActions` | Exportierte Vue-Komponente dieses Moduls. |
| `ItemContent` | Enthält den sichtbaren Inhalt. |
| `ItemDescription` | Zeigt ergänzende Beschreibung. |
| `ItemFooter` | Strukturiert den Fußbereich. |
| `ItemGroup` | Gruppiert zusammengehörige Elemente. |
| `ItemHeader` | Strukturiert den Kopfbereich. |
| `ItemMedia` | Exportierte Vue-Komponente dieses Moduls. |
| `ItemSeparator` | Trennt benachbarte Bereiche. |
| `ItemTitle` | Zeigt den zugänglichen Titel. |
