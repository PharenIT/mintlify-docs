Mit **Alert** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="alert" title="Alert Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Alert, AlertDescription, AlertTitle } from '@pharen/ui';
</script>

<template>
  <Alert>
    <AlertTitle>Changes saved</AlertTitle>
    <AlertDescription>Your workspace settings are up to date.</AlertDescription>
  </Alert>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Alert, AlertAction, AlertContent, AlertDescription, AlertIcon, AlertTitle, AlertToolbar } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Alert` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertAction` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertContent` | Enthält den sichtbaren Inhalt. |
| `AlertDescription` | Zeigt ergänzende Beschreibung. |
| `AlertIcon` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertTitle` | Zeigt den zugänglichen Titel. |
| `AlertToolbar` | Exportierte Vue-Komponente dieses Moduls. |
