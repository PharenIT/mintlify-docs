Mit **Scroll area** kannst du Inhalte und responsive Bereiche anzuordnen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { ScrollArea, ScrollBar } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { ScrollArea } from '@pharen/ui';
</script>

<template>
  <ScrollArea />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `ScrollArea` | Exportierte Vue-Komponente dieses Moduls. |
| `ScrollBar` | Exportierte Vue-Komponente dieses Moduls. |
