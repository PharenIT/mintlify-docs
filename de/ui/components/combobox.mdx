Mit **Combobox** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="combobox" title="Combobox Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Combobox, ComboboxItem } from '@pharen/ui';
</script>

<template>
  <Combobox>
    <ComboboxItem>First item</ComboboxItem>
  </Combobox>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Combobox, ComboboxAnchor, ComboboxEmpty, ComboboxGroup, ComboboxInput, ComboboxItem, ComboboxItemIndicator, ComboboxList, ComboboxSeparator, ComboboxViewport, ComboboxCancel, ComboboxTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |

| `Combobox` | Exportierte Vue-Komponente dieses Moduls. |
| `ComboboxAnchor` | Exportierte Vue-Komponente dieses Moduls. |
| `ComboboxEmpty` | Exportierte Vue-Komponente dieses Moduls. |
| `ComboboxGroup` | Gruppiert zusammengehörige Elemente. |
| `ComboboxInput` | Exportierte Vue-Komponente dieses Moduls. |
| `ComboboxItem` | Stellt ein einzelnes Element dar. |
| `ComboboxItemIndicator` | Exportierte Vue-Komponente dieses Moduls. |
| `ComboboxList` | Exportierte Vue-Komponente dieses Moduls. |
| `ComboboxSeparator` | Trennt benachbarte Bereiche. |
