Mit **Command** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Command, CommandDialog, CommandEmpty, CommandGroup, CommandInput, CommandItem, CommandList, CommandSeparator, CommandShortcut } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Command, CommandItem } from '@pharen/ui';
</script>

<template>
  <Command>
    <CommandItem>First item</CommandItem>
  </Command>
</template>
```
