Mit **Alert dialog** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="alert-dialog" title="Alert dialog Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { AlertDialog, AlertDialogTrigger, AlertDialogContent } from '@pharen/ui';
</script>

<template>
  <AlertDialog>
    <AlertDialogTrigger>Open alert dialog</AlertDialogTrigger>
    <AlertDialogContent>Alert dialog content</AlertDialogContent>
  </AlertDialog>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { AlertDialog, AlertDialogAction, AlertDialogCancel, AlertDialogContent, AlertDialogDescription, AlertDialogFooter, AlertDialogHeader, AlertDialogMedia, AlertDialogOverlay, AlertDialogPortal, AlertDialogTitle, AlertDialogTrigger } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `AlertDialog` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertDialogAction` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertDialogCancel` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertDialogContent` | Enthält den sichtbaren Inhalt. |
| `AlertDialogDescription` | Zeigt ergänzende Beschreibung. |
| `AlertDialogFooter` | Strukturiert den Fußbereich. |
| `AlertDialogHeader` | Strukturiert den Kopfbereich. |
| `AlertDialogMedia` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertDialogOverlay` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertDialogPortal` | Exportierte Vue-Komponente dieses Moduls. |
| `AlertDialogTitle` | Zeigt den zugänglichen Titel. |
| `AlertDialogTrigger` | Öffnet oder aktiviert die Komponente. |
