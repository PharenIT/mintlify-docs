Mit **Toggle group** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="toggle-group" title="Toggle group Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { ToggleGroup, ToggleGroupItem } from '@pharen/ui';

const alignment = ref('left');
</script>

<template>
  <ToggleGroup v-model="alignment" type="single" variant="outline" :spacing="0">
    <ToggleGroupItem value="left" aria-label="Align left">Left</ToggleGroupItem>
    <ToggleGroupItem value="center" aria-label="Align center">Center</ToggleGroupItem>
    <ToggleGroupItem value="right" aria-label="Align right">Right</ToggleGroupItem>
  </ToggleGroup>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { ToggleGroup, ToggleGroupItem } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `ToggleGroup` | Gruppiert zusammengehörige Elemente. |
| `ToggleGroupItem` | Stellt ein einzelnes Element dar. |
