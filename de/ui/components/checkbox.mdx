Mit **Checkbox** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Checkbox } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Checkbox, Label } from '@pharen/ui';
</script>

<template>
  <div class="flex items-center gap-2">
    <Checkbox id="updates" />
    <Label for="updates">Email me product updates</Label>
  </div>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Checkbox` | Exportierte Vue-Komponente dieses Moduls. |
