Mit **Checkbox** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="checkbox" title="Checkbox Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Checkbox, Label } from '@pharen/ui';
</script>

<template>
  <div class="flex items-center gap-2">
    <Checkbox id="updates" />
    <Label for="updates">Email me product updates</Label>
  </div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Checkbox } from '@pharen/ui';
```
