Mit **Aspect ratio** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="aspect-ratio" title="Aspect ratio Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { AspectRatio } from '@pharen/ui';
</script>

<template>
  <AspectRatio :ratio="16 / 9" class="w-full max-w-md overflow-hidden rounded-xl bg-muted">
    <div class="grid size-full place-items-center bg-primary/10 text-sm font-medium text-primary">
      16:9 preview
    </div>
  </AspectRatio>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { AspectRatio } from '@pharen/ui';
```
