Mit **Frame** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="frame" title="Frame Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Frame, FrameDescription, FrameFooter, FrameHeader, FramePanel, FrameTitle } from '@pharen/ui';
</script>

<template>
  <Frame class="w-full max-w-md">
    <FrameHeader>
      <FrameTitle>Agent activity</FrameTitle>
      <FrameDescription>Latest run for the research agent.</FrameDescription>
    </FrameHeader>
    <FramePanel>
      <div class="flex items-center justify-between text-sm">
        <span>Processed documents</span><strong>24</strong>
      </div>
    </FramePanel>
    <FrameFooter><span class="text-xs text-muted-foreground">Updated just now</span></FrameFooter>
  </Frame>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Frame, FrameDescription, FrameFooter, FrameHeader, FramePanel, FrameTitle } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Frame` | Exportierte Vue-Komponente dieses Moduls. |
| `FrameDescription` | Zeigt ergänzende Beschreibung. |
| `FrameFooter` | Strukturiert den Fußbereich. |
| `FrameHeader` | Strukturiert den Kopfbereich. |
| `FramePanel` | Exportierte Vue-Komponente dieses Moduls. |
| `FrameTitle` | Zeigt den zugänglichen Titel. |
