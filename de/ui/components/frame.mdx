Mit **Frame** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Frame, FrameDescription, FrameFooter, FrameHeader, FramePanel, FrameTitle } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Frame } from '@pharen/ui';
</script>

<template>
  <Frame />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Frame` | Exportierte Vue-Komponente dieses Moduls. |
| `FrameDescription` | Zeigt ergänzende Beschreibung. |
| `FrameFooter` | Strukturiert den Fußbereich. |
| `FrameHeader` | Strukturiert den Kopfbereich. |
| `FramePanel` | Exportierte Vue-Komponente dieses Moduls. |
| `FrameTitle` | Zeigt den zugänglichen Titel. |
