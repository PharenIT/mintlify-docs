Mit **Radio group** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="radio-group" title="Radio group Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Label, RadioGroup, RadioGroupItem } from '@pharen/ui';

const plan = ref('pro');
</script>

<template>
  <RadioGroup v-model="plan" class="grid gap-3">
    <div class="flex items-center gap-2"><RadioGroupItem id="starter" value="starter" /><Label for="starter">Starter</Label></div>
    <div class="flex items-center gap-2"><RadioGroupItem id="pro" value="pro" /><Label for="pro">Pro</Label></div>
  </RadioGroup>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { RadioGroup, RadioGroupItem } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `RadioGroup` | Gruppiert zusammengehörige Elemente. |
| `RadioGroupItem` | Stellt ein einzelnes Element dar. |
