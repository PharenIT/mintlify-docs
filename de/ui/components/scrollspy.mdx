Mit **Scrollspy** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Scrollspy } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Scrollspy } from '@pharen/ui';
</script>

<template>
  <Scrollspy />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Scrollspy` | Exportierte Vue-Komponente dieses Moduls. |
