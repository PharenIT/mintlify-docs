Mit **Filters** kannst du mit strukturierten operativen Daten zu arbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Filters, FilterInput, FilterValueSelector } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Filters } from '@pharen/ui';
import { ref } from 'vue';
import type { Filter, FilterFieldConfig } from '@pharen/ui';

const filters = ref<Filter[]>([]);
const fields: FilterFieldConfig[] = [
  { id: 'status', label: 'Status', type: 'select', options: [
    { label: 'Active', value: 'active' },
    { label: 'Paused', value: 'paused' },
  ] },
];
</script>

<template>
  <Filters v-model="filters" :fields="fields" />
</template>
```
