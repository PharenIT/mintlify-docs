Mit **Tooltip** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="tooltip" title="Tooltip Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Button, Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from '@pharen/ui';
</script>

<template>
  <TooltipProvider>
    <Tooltip>
      <TooltipTrigger as-child><Button variant="outline">Hover or focus</Button></TooltipTrigger>
      <TooltipContent>Open workspace settings</TooltipContent>
    </Tooltip>
  </TooltipProvider>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Tooltip, TooltipProvider, TooltipTrigger, TooltipContent } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Tooltip` | Exportierte Vue-Komponente dieses Moduls. |
| `TooltipProvider` | Exportierte Vue-Komponente dieses Moduls. |
| `TooltipTrigger` | Öffnet oder aktiviert die Komponente. |
| `TooltipContent` | Enthält den sichtbaren Inhalt. |
