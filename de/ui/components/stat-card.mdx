Mit **Stat card** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="stat-card" title="Stat card Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { StatCard } from '@pharen/ui';
</script>

<template>
  <StatCard label="Workflow runs" :value="128" delta="12%" trend="up" />
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { StatCard } from '@pharen/ui';
```
