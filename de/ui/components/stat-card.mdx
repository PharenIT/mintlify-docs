Mit **Stat card** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { StatCard } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { StatCard } from '@pharen/ui';
</script>

<template>
  <StatCard label="Workflow runs" :value="128" delta="12%" trend="up" />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `StatCard` | Exportierte Vue-Komponente dieses Moduls. |
