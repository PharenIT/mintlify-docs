Mit **Empty state** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { EmptyState } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { EmptyState } from '@pharen/ui';
</script>

<template>
  <EmptyState />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `EmptyState` | Exportierte Vue-Komponente dieses Moduls. |
