Mit **Empty state** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="empty-state" title="Empty state Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { EmptyState } from '@pharen/ui';
</script>

<template>
  <EmptyState
    title="No results found"
    description="Try another search term or clear the filters."
    :icons="['lucide:search', 'lucide:filter', 'lucide:files']"
  />
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { EmptyState } from '@pharen/ui';
```
