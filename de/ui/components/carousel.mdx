Mit **Carousel** kannst du Inhalte und responsive Bereiche anzuordnen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="carousel" title="Carousel Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Carousel, CarouselItem } from '@pharen/ui';
</script>

<template>
  <Carousel>
    <CarouselItem>First item</CarouselItem>
  </Carousel>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Carousel, CarouselContent, CarouselItem, CarouselNext, CarouselPrevious } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Carousel` | Exportierte Vue-Komponente dieses Moduls. |
| `CarouselContent` | Enthält den sichtbaren Inhalt. |
| `CarouselItem` | Stellt ein einzelnes Element dar. |
| `CarouselNext` | Exportierte Vue-Komponente dieses Moduls. |
| `CarouselPrevious` | Exportierte Vue-Komponente dieses Moduls. |
