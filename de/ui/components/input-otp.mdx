Mit **Input OTP** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="input-otp" title="Input OTP Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { InputOTP, InputOTPGroup, InputOTPSlot } from '@pharen/ui';

const code = ref(['4', '2']);
</script>

<template>
  <InputOTP v-model="code" :maxlength="6">
    <InputOTPGroup><InputOTPSlot v-for="index in 6" :key="index" :index="index - 1" /></InputOTPGroup>
  </InputOTP>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { InputOTP, InputOTPGroup, InputOTPSeparator, InputOTPSlot } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `InputOTP` | Exportierte Vue-Komponente dieses Moduls. |
| `InputOTPGroup` | Gruppiert zusammengehörige Elemente. |
| `InputOTPSeparator` | Trennt benachbarte Bereiche. |
| `InputOTPSlot` | Exportierte Vue-Komponente dieses Moduls. |
