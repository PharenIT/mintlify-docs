Mit **Tabs** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@pharen/ui';
</script>

<template>
  <Tabs default-value="overview">
    <TabsList>
      <TabsTrigger value="overview">Overview</TabsTrigger>
      <TabsTrigger value="activity">Activity</TabsTrigger>
    </TabsList>
    <TabsContent value="overview">Workspace overview</TabsContent>
    <TabsContent value="activity">Recent activity</TabsContent>
  </Tabs>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Tabs` | Exportierte Vue-Komponente dieses Moduls. |
| `TabsContent` | Enthält den sichtbaren Inhalt. |
| `TabsList` | Exportierte Vue-Komponente dieses Moduls. |
| `TabsTrigger` | Öffnet oder aktiviert die Komponente. |
