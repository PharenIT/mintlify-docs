Mit **Sonner** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Sonner, Toaster } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Sonner } from '@pharen/ui';
</script>

<template>
  <Sonner />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Sonner` | Exportierte Vue-Komponente dieses Moduls. |
| `Toaster` | Exportierte Vue-Komponente dieses Moduls. |
