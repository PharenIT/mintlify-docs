Mit **Sonner** kannst du kontextbezogene Inhalte oder Feedback anzuzeigen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="sonner" title="Sonner Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { onMounted } from 'vue';
import { Button, Sonner, toast } from '@pharen/ui';

const showToast = () => toast.success('Workflow published', { description: 'The automation is now active.', duration: Infinity });
onMounted(showToast);
</script>

<template>
  <div><Button variant="outline" @click="showToast">Show notification</Button><Sonner position="top-center" /></div>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Sonner, Toaster } from '@pharen/ui';
```
