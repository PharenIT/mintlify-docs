Mit **Resizable** kannst du Inhalte und responsive Bereiche anzuordnen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from '@pharen/ui';
</script>

<template>
  <ResizablePanelGroup direction="horizontal" class="h-56 w-full max-w-lg overflow-hidden rounded-xl border">
    <ResizablePanel :default-size="35"><div class="grid size-full place-items-center bg-muted/40 text-sm font-medium">Sidebar</div></ResizablePanel>
    <ResizableHandle with-handle />
    <ResizablePanel :default-size="65"><div class="grid size-full place-items-center text-sm font-medium">Content</div></ResizablePanel>
  </ResizablePanelGroup>

```

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |

| `ResizablePanel` | Exportierte Vue-Komponente dieses Moduls. |
| `ResizablePanelGroup` | Gruppiert zusammengehörige Elemente. |
