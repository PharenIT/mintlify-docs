Mit **Slider** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Slider } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Slider } from '@pharen/ui';
</script>

<template>
  <Slider :default-value="[40]" :max="100" :step="1" />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Slider` | Exportierte Vue-Komponente dieses Moduls. |
