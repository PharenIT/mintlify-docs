Mit **Slider** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="slider" title="Slider Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Slider } from '@pharen/ui';
</script>

<template>
  <Slider :default-value="[40]" :max="100" :step="1" />
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Slider } from '@pharen/ui';
```
