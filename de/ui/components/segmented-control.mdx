Mit **Segmented control** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { SegmentedControl } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { SegmentedControl } from '@pharen/ui';
</script>

<template>
  <SegmentedControl />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `SegmentedControl` | Exportierte Vue-Komponente dieses Moduls. |
