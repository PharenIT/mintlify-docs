Mit **Pagination** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Pagination, PaginationContent, PaginationEllipsis, PaginationFirst, PaginationItem, PaginationLast, PaginationLink, PaginationNext, PaginationPrevious } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Pagination, PaginationItem } from '@pharen/ui';
</script>

<template>
  <Pagination>
    <PaginationItem>First item</PaginationItem>
  </Pagination>
</template>
```
