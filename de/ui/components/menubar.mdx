Mit **Menubar** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Menubar, MenubarCheckboxItem, MenubarContent, MenubarGroup, MenubarItem, MenubarLabel, MenubarMenu, MenubarPortal, MenubarRadioGroup, MenubarRadioItem, MenubarSeparator, MenubarShortcut, MenubarSub, MenubarSubContent, MenubarSubTrigger, MenubarTrigger } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Menubar, MenubarTrigger, MenubarContent } from '@pharen/ui';
</script>

<template>
  <Menubar>
    <MenubarTrigger>Open menubar</MenubarTrigger>
    <MenubarContent>Menubar content</MenubarContent>
  </Menubar>
</template>
```
