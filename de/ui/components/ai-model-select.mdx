Mit **AI model select** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="ai-model-select" title="AI model select Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { AiModelSelect } from '@pharen/ui';

const model = ref('gpt-5.4');
const models = [
  { id: 'gpt-5.4', name: 'GPT-5.4', provider: 'OpenAI', icon: 'simple-icons:openai', supportsThinking: true },
  { id: 'claude-opus', name: 'Claude Opus', provider: 'Anthropic', icon: 'simple-icons:anthropic', supportsThinking: true },
  { id: 'gemini-pro', name: 'Gemini Pro', provider: 'Google', icon: 'simple-icons:googlegemini' },
];
</script>

<template>
  <AiModelSelect v-model="model" :models="models" class="w-full max-w-sm" show-thinking-toggle />
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { AiModelSelect, AiModelIcon, AiModelSelectItem } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `AiModelSelect` | Exportierte Vue-Komponente dieses Moduls. |
| `AiModelIcon` | Exportierte Vue-Komponente dieses Moduls. |
| `AiModelSelectItem` | Stellt ein einzelnes Element dar. |
