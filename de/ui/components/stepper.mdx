Mit **Stepper** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Stepper, StepperContent, StepperDescription, StepperIndicator, StepperItem, StepperNav, StepperPanel, StepperSeparator, StepperTitle, StepperTrigger } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Stepper, StepperTrigger, StepperContent } from '@pharen/ui';
</script>

<template>
  <Stepper>
    <StepperTrigger>Open stepper</StepperTrigger>
    <StepperContent>Stepper content</StepperContent>
  </Stepper>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Stepper` | Exportierte Vue-Komponente dieses Moduls. |
| `StepperContent` | Enthält den sichtbaren Inhalt. |
| `StepperDescription` | Zeigt ergänzende Beschreibung. |
| `StepperIndicator` | Exportierte Vue-Komponente dieses Moduls. |
| `StepperItem` | Stellt ein einzelnes Element dar. |
| `StepperNav` | Exportierte Vue-Komponente dieses Moduls. |
| `StepperPanel` | Exportierte Vue-Komponente dieses Moduls. |
| `StepperSeparator` | Trennt benachbarte Bereiche. |
| `StepperTitle` | Zeigt den zugänglichen Titel. |
| `StepperTrigger` | Öffnet oder aktiviert die Komponente. |
