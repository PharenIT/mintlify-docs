Mit **Detail icon nav** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { DetailIconNav } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { DetailIconNav } from '@pharen/ui';
</script>

<template>
  <DetailIconNav />
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `DetailIconNav` | Exportierte Vue-Komponente dieses Moduls. |
