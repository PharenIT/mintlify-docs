Mit **Rating** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="rating" title="Rating Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Rating } from '@pharen/ui';

const value = ref(4);
</script>

<template><Rating v-model="value" size="lg" /></template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Rating } from '@pharen/ui';
```
