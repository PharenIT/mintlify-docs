Mit **Sortable** kannst du mit strukturierten operativen Daten zu arbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="sortable" title="Sortable Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Sortable, SortableItem, SortableItemHandle } from '@pharen/ui';

const tasks = ref([
  { id: 'research', label: 'Research competitors' },
  { id: 'draft', label: 'Draft campaign' },
  { id: 'review', label: 'Review copy' },
]);
</script>

<template>
  <Sortable v-model="tasks" :get-item-value="item => item.id" class="grid w-full max-w-sm gap-2">
    <SortableItem v-for="task in tasks" :key="task.id" :value="task.id" class="flex items-center gap-2 rounded-lg border bg-card p-3">
      <SortableItemHandle :label="`Move ${task.label}`" />
      <span class="text-sm">{{ task.label }}</span>
    </SortableItem>
  </Sortable>
</template>
```

</Accordion>

## Installation

```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Sortable, SortableItem, SortableItemHandle, SortableOverlay } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
