Mit **Sortable** kannst du mit strukturierten operativen Daten zu arbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Sortable, SortableItem, SortableItemHandle, SortableOverlay } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Sortable, SortableItem } from '@pharen/ui';
</script>

<template>
  <Sortable>
    <SortableItem>First item</SortableItem>
  </Sortable>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Sortable` | Exportierte Vue-Komponente dieses Moduls. |
| `SortableItem` | Stellt ein einzelnes Element dar. |
| `SortableItemHandle` | Exportierte Vue-Komponente dieses Moduls. |
| `SortableOverlay` | Exportierte Vue-Komponente dieses Moduls. |
