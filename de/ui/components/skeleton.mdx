Mit **Skeleton** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Skeleton } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Skeleton } from '@pharen/ui';
</script>

<template>
  <div class="grid gap-2">
    <Skeleton class="h-4 w-48" />
    <Skeleton class="h-4 w-32" />
  </div>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Skeleton` | Exportierte Vue-Komponente dieses Moduls. |
