Mit **Avatar group** kannst du strukturierte Produktinformationen darzustellen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="avatar-group" title="Avatar group Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { AvatarGroup } from '@pharen/ui';

const people = [
  { fallback: 'JK', alt: 'Johannes Kanthak' },
  { fallback: 'AM', alt: 'Alex Morgan' },
  { fallback: 'SL', alt: 'Sam Lee' },
  { fallback: 'RK', alt: 'Robin Kim' },
  { fallback: 'TN', alt: 'Taylor Nguyen' },
];
</script>

<template>
  <AvatarGroup :items="people" :max="4" size="base" />
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { AvatarGroup, AvatarGroupCount } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `AvatarGroup` | Gruppiert zusammengehörige Elemente. |
| `AvatarGroupCount` | Exportierte Vue-Komponente dieses Moduls. |
