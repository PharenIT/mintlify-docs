Mit **Toggle** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Toggle } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Toggle } from '@pharen/ui';
</script>

<template>
  <Toggle aria-label="Toggle bold">Bold</Toggle>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Toggle` | Exportierte Vue-Komponente dieses Moduls. |
