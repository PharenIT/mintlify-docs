Mit **Tree** kannst du eine Aktion oder Navigation aufzubauen. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<Note>
  Installiere das Paket und importiere die Styles einmalig. Die vollständigen Schritte findest du unter [Installation](/de/ui/installation).
</Note>

## Import

```ts
import { Tree, TreeDragLine, TreeItem, TreeItemLabel } from '@pharen/ui';
```

## Beispiel

```vue
<script setup lang="ts">
import { Tree, TreeItem } from '@pharen/ui';
</script>

<template>
  <Tree>
    <TreeItem>First item</TreeItem>
  </Tree>
</template>
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Tree` | Exportierte Vue-Komponente dieses Moduls. |
| `TreeDragLine` | Exportierte Vue-Komponente dieses Moduls. |
| `TreeItem` | Stellt ein einzelnes Element dar. |
| `TreeItemLabel` | Beschriftet einen Wert oder Bereich. |
