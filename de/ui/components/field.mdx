Mit **Field** kannst du einen Wert zu erfassen oder zu bearbeiten. Diese Seite dokumentiert alle Vue-Komponenten, die das Modul öffentlich exportiert.

<PharenUiPreview name="field" title="Field Vorschau" />

<Accordion title="Code anzeigen">

```vue
<script setup lang="ts">
import { Field, FieldDescription, FieldLabel, Input } from '@pharen/ui';
</script>

<template>
  <Field class="w-full max-w-sm">
    <FieldLabel for="workspace-name">Workspace name</FieldLabel>
    <Input id="workspace-name" value="Pharen" />
    <FieldDescription>This name is visible to every workspace member.</FieldDescription>
  </Field>
</template>
```

</Accordion>

## Installation

<CodeGroup>
```bash npm
npm install @pharen/ui
```

```bash pnpm
pnpm add @pharen/ui
```

```bash yarn
yarn add @pharen/ui
```

```bash bun
bun add @pharen/ui
```
</CodeGroup>

<Note>
  Importiere `@pharen/ui/styles.css` genau einmal im Einstiegspunkt deiner Anwendung.
</Note>

## Verwendung

```ts
import { Field, FieldContent, FieldDescription, FieldError, FieldGroup, FieldLabel, FieldLegend, FieldSeparator, FieldSet, FieldTitle } from '@pharen/ui';
```

## Exporte

| Export | Aufgabe |
| --- | --- |
| `Field` | Exportierte Vue-Komponente dieses Moduls. |
| `FieldContent` | Enthält den sichtbaren Inhalt. |
| `FieldDescription` | Zeigt ergänzende Beschreibung. |
| `FieldError` | Exportierte Vue-Komponente dieses Moduls. |
| `FieldGroup` | Gruppiert zusammengehörige Elemente. |
| `FieldLabel` | Beschriftet einen Wert oder Bereich. |
| `FieldLegend` | Exportierte Vue-Komponente dieses Moduls. |
| `FieldSeparator` | Trennt benachbarte Bereiche. |
| `FieldSet` | Exportierte Vue-Komponente dieses Moduls. |
| `FieldTitle` | Zeigt den zugänglichen Titel. |
